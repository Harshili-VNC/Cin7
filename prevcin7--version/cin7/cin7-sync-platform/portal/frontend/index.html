02 / SOURCE

Connect Cin7 Core

  1. Log in to your Cin7 Core account, then click Integration in the left-hand sidebar.

  2. Under Integrations, select the API category, then click the Cin7 Core API tile.

  3. Click the + icon to add a new API application.

  4. Type a name for it (e.g. Excel Sync) and click Create.

  5. Copy the API key shown in the popup right away — this is your Application Key, and it's only ever displayed once.

  6. On the application's details page, copy the Account ID shown there.

  7. Make sure Is active is switched ON. If it's off, syncing will fail even with the correct keys.

  8. Paste the Account ID and Application Key into the two fields below, then click Verify & Save.

04 / SCRIPT & BUTTON

Generate your personalized Excel script

Click below to generate your unique client key and complete Office Script tailored specifically for your Excel workbook.

Save this script in Excel via Automate → New Script, then click Run or add it to your Quick Access Toolbar.

  1. Click Generate Office Script & Key above — this creates your personalized script with your Client ID and API key already filled in, then click Copy Script to Clipboard.

  2. Open your Excel workbook and go to the Automate tab.

  3. Click New Script, then choose Create in Code Editor.

  4. The Code Editor opens with a starter script already in it.

  5. Select all of that starter code and delete it, leaving the editor blank.

  6. Paste in the script you copied in step 1.

  7. Click the save icon in the script toolbar and give it a name.

  8. Go back to Automate → All Scripts and click on your saved script to open its details.

  9. Turn on Associate with workbook, then click the now-enabled Add button to worksheet. A button will appear in your workbook that runs the sync with one click.
